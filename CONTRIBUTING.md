# Contributing to Kabil

Thank you for your interest in contributing to **Kabil - Chakma and Pali Voice Assistant**! We are building the first open-source voice assistant for these low-resource languages, and your help is invaluable.

## How to Contribute
You can contribute in several ways:
1. **Data Collection & Annotation:** We need native speakers to record audio and validate transcriptions for Chakma and Pali.
2. **Code & Models:** Help us train models (ASR, TTS, NLP), build the backend API, or optimize for embedded edge devices.
3. **Documentation:** Improve our docs, architecture diagrams, and tutorials.

## Workflow
1. Fork the repository.
2. Create a new branch for your feature (`git checkout -b feature/your-feature-name`).
3. Commit your changes following standard Git commit message conventions.
4. Push to the branch (`git push origin feature/your-feature-name`).
5. Open a Pull Request.

Please read our [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) before participating.
